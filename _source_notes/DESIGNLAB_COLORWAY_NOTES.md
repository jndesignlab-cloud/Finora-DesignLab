# Finora v2.0.7 — DesignLab Colorway Notes

This update keeps the softer Finsights-inspired layout from v2.0.4 but replaces the yellow/lime treatment with the DesignLab color system.

## Applied palette

- Deep navy text: `#071a35`
- Royal blue primary: `#2557ff`
- Electric cyan support: `#20c8ff`
- Violet support accent: `#7b61ff`
- Light app background: `#f7faff`
- Soft card background: `#ffffff` / `#f2f6ff`

## UI changes

- Blue-led gradient brand mark
- Blue-led primary buttons
- Blue active sidebar state
- Blue/violet net worth card glow
- Blue progress bars
- Soft blue account icon tiles
- Updated PWA icon and manifest theme color

Violet remains supporting only, not the dominant color.
