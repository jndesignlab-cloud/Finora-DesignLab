# Finora Terms of Use

Finora by DesignLab is a personal finance tracking and planning tool.

## No professional advice

Finora does not provide financial, accounting, tax, investment, legal, or debt-management advice. It only records and summarizes information entered by the user.

## User responsibility

The owner is responsible for:

- Entering accurate data
- Reviewing figures before making financial decisions
- Protecting the login password and recovery code
- Protecting Supabase dashboard access
- Exporting backups when needed
- Keeping the deployment private if used for personal or in-house purposes

## Availability

Finora depends on the configured hosting provider, browser, internet connection, and Supabase project availability.

## Public launch warning

Before offering Finora to other users, replace the personal auth model with a production authentication model, review privacy/legal requirements, and prepare support, deletion, and security processes.
